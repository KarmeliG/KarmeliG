# Portfolio Roadmap

This portfolio is designed to demonstrate how I approach AI-enabled operations, automation, evaluation, and systems design without exposing employer or client intellectual property.

## Portfolio principles

- Build independent implementations from scratch.
- Use fictional organizations and synthetic data.
- Never publish employer or client source code, prompts, datasets, screenshots, credentials, internal documentation, pricing, or proprietary workflows.
- Focus on the problem, architecture, tradeoffs, testing, and measurable outcomes.
- Prefer a small number of polished, working projects over many unfinished demos.

## What a strong project should include

Each project should eventually have:

1. A clear problem statement
2. Architecture diagram
3. Working code or prototype
4. Synthetic sample data
5. Setup instructions
6. Design decisions and tradeoffs
7. Testing/evaluation approach
8. Screenshots or demo GIFs when useful
9. A short section explaining what I would change for production

## Public portfolio safety checklist

Before publishing any project, confirm:

- [ ] All names are fictional
- [ ] All data is synthetic
- [ ] No employer/client code was copied
- [ ] No proprietary prompts or templates were copied
- [ ] No internal screenshots are included
- [ ] No API keys or secrets are committed
- [ ] Pricing and business rules are fictional unless intentionally public
- [ ] The README clearly states that the implementation is independent
